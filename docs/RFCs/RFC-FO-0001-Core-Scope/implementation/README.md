# RFC-FO-0001 — FullObservability Core Scope Implementation Profile

**Pairs with:** ../semantic.md

This directory is descriptive. It defines one reference implementation profile and MUST NOT be treated as conformance evidence.

For the TypeScript reference implementation, technology bindings MAY include OpenTelemetry SDKs, Node.js, SQLite/PostgreSQL drivers and realtime transport adapters. Other language ports MAY choose different technologies while preserving semantic requirements.
