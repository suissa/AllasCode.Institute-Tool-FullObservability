# RFC-FO-0010 — Cross-language Conformance

**Status:** Draft Standard

## Scope
Language-neutral semantic authority.

## Normative requirements

### FO-CONF-001
semantic.md MUST remain the language-neutral authority.

### FO-CONF-002
Each language port MUST prove applicable requirements with executable tests.

### FO-CONF-003
Wire-incompatible changes MUST introduce a new protocol or format version.

### FO-CONF-004
Conformance manifests MUST NOT claim unverified implementation.

## Implementation boundary
Technology choices belong to `implementation/` and MUST preserve these semantics.
